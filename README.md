# Operational Research Visualizer

A visual tool built with **Scala** and the **Doodle** library to help understand and conceptualize Operational Research algorithms. 

This application bridges the gap between abstract mathematical theory and spatial visualization. By leveraging pure functional programming principles, it renders complex graphs, pathfinding algorithms, and network flows into clear, composable vector graphics.

## Features

* **Graph Visualization:** Clean, automated rendering of nodes, edges, and weights.
* **Algorithm Tracking:** Visually highlights shortest paths, spanning trees, and graph states.
* **Functional Architecture:** Built entirely with immutable data structures and pure functions, avoiding side effects for predictable rendering.

## Tech Stack

* **Language:** Scala
* **Graphics:** [Doodle](https://github.com/creativescala/doodle) (2D vector graphics library)
* **Build Tool:** sbt
